# Scarpy's Personal Web Page

A personal portfolio website built with HTML, CSS, and TailwindCSS.

## Features

- 📱 Responsive design with TailwindCSS v4
- ❄️ Animated snow effect
- 🎨 Clean and modern layout
- 🔗 Navigation menu with multiple sections

## Technologies Used

- HTML5
- CSS3
- [TailwindCSS v4](https://tailwindcss.com/) (via CDN)

## Project Structure

```
PersonalWeb/
├── index.html    # Main HTML page
├── main.css      # Custom CSS styles
└── README.md     # Project documentation
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sergio-D-Vico-Pineda/PersonalWeb.git
   ```

2. Open `index.html` in your web browser.
